# Xcx作品集1.0版本

徐晨晓个人作品集。React + TypeScript + Vite + Tailwind CSS。

## 发布

通过 GitHub Actions 部署到 GitHub Pages。仓库 Settings → Pages 的 Source 选择 GitHub Actions。

```sh
npm install
npm run build
```

发布内容在 publication/content.json，图片和视频在 public/。公开页面仅供浏览，不包含编辑、上传或换图入口，也不依赖访问者的浏览器存储。

广告完整版使用网页压缩版本，原始视频仍保留在本地项目中。
